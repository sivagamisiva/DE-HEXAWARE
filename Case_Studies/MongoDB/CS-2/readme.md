# 📚 Zen Class Program – MongoDB Case Study

This case study showcases my hands-on experience with MongoDB Compass, where I worked with real-time student-related data such as users, attendance, tasks, topics, mentors, and company drives. I created and managed collections, imported JSON data, executed practical queries, and documented insights.

---

## 🔍 Overview

In this case study, I explored MongoDB using MongoDB Compass and Mongo Shell to build and manage a NoSQL database for the Zen Class Program. The dataset includes 8 different collections representing student activity, mentor data, tasks, and placement drives.

---

## ⚙️ What I Did

### ✅ 1. MongoDB Setup
- Opened MongoDB Compass and connected to the local MongoDB server.
- Created a new database named `zenclass`.

### ✅ 2. Collection Creation & Import
Created the following 8 collections and imported JSON data into each:

- `users`
- `codekata`
- `attendance`
- `topics`
- `tasks`
- `task_completion`
- `companydrives`
- `mentors`

Each collection was verified using Mongo Shell (`db.collection.find().pretty()`).

### ✅ 3. Query Execution

Executed the following real-time MongoDB queries:

1. **Topics and tasks in October 2023**
2. **Company drives between 15-Oct and 31-Oct 2023**
3. **Total problems solved by users in Codekata**
4. **Mentors with more than 15 mentees**
5. **Users who were absent and didn’t submit tasks between 15–31 Oct**

---

## 📘 What I Learned

- How to **create and manage MongoDB databases and collections** using MongoDB Compass.
- How to **import JSON data** into collections.
- How to **query structured documents** using both field filtering and aggregation.
- The difference between **string vs. ISODate formats** in queries.
