# 📘 MongoDB Product Collection Project

This project focuses on working with MongoDB using Compass and Shell to manage a product collection. It involves creating a database, inserting JSON documents, and performing basic operations like filtering and retrieving product data.

---

## 🗂️ 1. Project Overview

In this project, I worked with MongoDB to:
- Create a new database and collection
- Insert sample product data using JSON
- Explore and filter data using Mongo Shell
- Practice data retrieval and cleanup tasks

The goal was to understand how MongoDB handles real-world document-based data using basic operations.

---

## 🧭 2. Steps Followed

1. Opened MongoDB Compass to begin the project.
2. Created a new database named `productdb` and a collection named `product`.
3. Inserted 20 product documents using the import JSON option.
4. Accessed Mongo Shell in Compass to run operations on the collection.
5. Executed different data retrieval and filtering operations based on product attributes like price, color, and material.
6. Managed duplicate entries based on product price using MongoDB's aggregation features.

---

## 📊 3. Key Learning Outcomes

- Learned how to navigate MongoDB Compass.
- Understood how to create and manage collections.
- Gained experience in inserting structured JSON data.
- Practiced basic query operations using Mongo Shell.
- Improved understanding of document-based data filtering.

---

## ✅ 4. Tools Used

- **MongoDB Compass**: For GUI-based database creation and data handling.
- **Mongo Shell**: For running commands and interacting with the database.
- **JSON Format**: For inserting multiple product records into the collection.
